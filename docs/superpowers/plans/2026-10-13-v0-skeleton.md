# Aether Nexus v0 Skeleton — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `nexus` CLI that drives one task (moon) through emit → launch → audit → review → dock against an append-only SQLite event log, with a fake provider adapter proving the whole lifecycle in CI, and real Claude-SDK / Codex-MCP adapters behind the same interface.

**Architecture:** One Node/TypeScript process per repo ("galaxy"). `events` is the source of truth; every other table is a projection rebuilt by replaying events through pure reducers. Work runs in git worktrees on `nexus/<task-id>` branches and merges into planet branches; the human's working branch is never written to. Providers are adapters that yield normalized `AgentEvent`s.

**Tech Stack:** Node ≥ 22.13, TypeScript 5 (`tsc` → `dist/`), `node:sqlite`, `node:test`, `@anthropic-ai/claude-agent-sdk`, `@modelcontextprotocol/sdk` (1.x). No other runtime dependencies.

**Spec:** `docs/superpowers/specs/2026-10-13-v0-skeleton-design.md` (parent: `docs/2026-10-10-aether-nexus-design.md`). Read both before starting any task.

## Global Constraints

- `engines.node >= 22.13`; CI runs Node 22 and 24 on ubuntu, windows, macos. Everything must pass on Windows (paths, line endings, `git worktree` leftovers).
- Runtime dependencies are exactly: `@anthropic-ai/claude-agent-sdk`, `@modelcontextprotocol/sdk`. Dev: `typescript`. Nothing else without amending the spec.
- All SQL lives in `src/db/statements.ts` or `src/db/migrations/*.sql`. A test enforces it.
- Every DB write is one `BEGIN IMMEDIATE … COMMIT` per event; no transaction is held while an agent streams. `PRAGMA busy_timeout = 5000` on open (the `timeout` constructor option needs Node 22.16; we are on 22.14 — use the PRAGMA).
- Reducers are pure: they read the event row and projection rows only. Never clock, fs, git, or config.
- Git is always invoked as `git -c core.quotepath=false -C <path> …`; never relies on CWD. The refusal list (§4.4) is enforced in code and tested: no `push`; no `checkout|switch|reset|stash` in the main worktree; `branch -D` only on `nexus/*` and `system/*`; `worktree remove` only under `.nexus/worktrees/`.
- IDs: `SAFE_ID = /^[A-Za-z0-9][A-Za-z0-9._-]*$/` for task ids; body ids are `<system>/<planet-name>[/<moon-name>]`.
- Spec header line is `NEXUS-SPEC:`; the immutable body is everything above `## Amendments`.
- `claude-sdk` in `login` mode deletes `ANTHROPIC_API_KEY` from the subprocess env.
- Text files are LF (`.gitattributes: * text=auto eol=lf`).
- Commit after every task with the message given; every commit ends with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
- Tests import from `dist/`; `npm test` builds first. Run the single file you are working on with `node --test tests/<dir>/<file>.test.mjs` after `npm run build`.

## Review Focus

Inputs the spec implies but no section tests directly; each gets a test in the owning task.

1. **A spec whose Touch table has a path with spaces or a backslash** → gate must normalize and still match (Task 2 adds the vector; Task 8 gates it).
2. **`moon assign` with a spec whose task id collides with an existing `moons.task_id`** → refused with the existing moon named, no event written (Task 10).
3. **Two `launch` processes racing on the same moon** → exactly one wins; the loser gets "moon is implementing" from the transition table, not a half-written voyage (Task 9 tests the transaction path with two connections).
4. **`dock` when the planet worktree has been deleted by hand** → check-before-act recreates it from the planet branch rather than crashing on a missing path (Task 7 + Task 12).
5. **A fake script that writes outside `touch` AND reports IMPLEMENTED** → audit, not the report, decides: moon goes `adrift` with `out_of_scope` listed (Task 14 e2e `scope-violation`).

```ts
// src/validate/spec.ts
import { createHash } from "node:crypto";

export const SAFE_ID = /^[A-Za-z0-9][A-Za-z0-9._-]*$/;
export function idError(id: string): string {
  return `ID '${id}' is not a canonical task ID — IDs name state files, branches, and worktrees verbatim and must match [A-Za-z0-9][A-Za-z0-9._-]*`;
}

export type ParsedSpec = {
  taskId: string | undefined; modelHint: string | undefined; gravity: number | undefined;
  dependsOn: string[]; touch: string[];
};

export function specBody(text: string): string {
  return text.split(/^## Amendments[ \t]*$/m)[0]!.replace(/\s+$/, "");
}
export function specAppendix(text: string): string {
  const m = text.match(/^## Amendments[ \t]*$/m);
  return m ? text.slice(m.index) : "";
}
export function sha256(data: string | Buffer): string {
  return createHash("sha256").update(data).digest("hex");
}
export function hashSpec(text: string): { bodySha: string; appendixSha: string } {
  return { bodySha: sha256(specBody(text)), appendixSha: sha256(specAppendix(text)) };
}

export function parseSpec(text: string): ParsedSpec {
  const body = specBody(text);
  const meta = (re: RegExp) => (body.match(re) || [])[1];
  const taskId = meta(/^\s*-\s+\*\*Task ID\*\*:\s*(\S+)/m);
  const modelHint = meta(/^\s*-\s+\*\*Model hint\*\*:\s*(\S+)/m);
  const gravityRaw = meta(/^\s*-\s+\*\*Gravity\*\*:\s*(\d+)/m);
  const depsRaw = meta(/^\s*-\s+\*\*Depends on\*\*:\s*(.+)$/m) ?? "";
  const dependsOn = depsRaw.trim().toLowerCase() === "none" ? [] :
    depsRaw.split(",").map((s) => s.trim()).filter(Boolean);
  const touchSection = (body.split(/^### Touch\s*$/m)[1] || "").split(/^### /m)[0]!;
  const touch: string[] = [];
  for (const m of touchSection.matchAll(/^\|\s*`([^`]+)`\s*\|/gm)) touch.push(m[1]!);
  return { taskId, modelHint, gravity: gravityRaw ? Number(gravityRaw) : undefined, dependsOn, touch };
}

export function appendAmendment(text: string, e: { round: number; date: string; author: string; note: string }): string {
  const hasSection = /^## Amendments[ \t]*$/m.test(text);
  const base = text.replace(/\s+$/, "") + "\n";
  const head = hasSection ? "" : "\n## Amendments\n";

// src/db/open.ts
import { DatabaseSync, type StatementSync } from "node:sqlite";
import fs from "node:fs"; import path from "node:path"; import { fileURLToPath } from "node:url";
import { STATEMENTS, type StatementName } from "./statements.js";

export type Row = Record<string, unknown>;
export type NexusDb = {
  raw: DatabaseSync; statsEnabled: boolean;
  run(name: StatementName, params?: Row): { changes: number; lastInsertRowid: number };
  get<T = Row>(name: StatementName, params?: Row): T | undefined;
  all<T = Row>(name: StatementName, params?: Row): T[];
  transaction<T>(fn: () => T): T;
  close(): void;
};

const MIGRATIONS_DIR = path.join(path.dirname(fileURLToPath(import.meta.url)), "migrations");

export function openDb(file: string, opts: { stats?: boolean } = {}): NexusDb {
  fs.mkdirSync(path.dirname(file), { recursive: true });
  const raw = new DatabaseSync(file);
  raw.exec("PRAGMA journal_mode = WAL");
  raw.exec("PRAGMA foreign_keys = ON");
  raw.exec("PRAGMA busy_timeout = 5000");
  migrate(raw);

  const cache = new Map<string, StatementSync>();
  const stmt = (name: StatementName): StatementSync => {
    let s = cache.get(name);
    if (!s) { const sql = STATEMENTS[name]; if (!sql) throw new Error(`unknown statement '${name}'`); s = raw.prepare(sql); cache.set(name, s); }
    return s;
  };
  const statsEnabled = opts.stats === true;
  const statsStmt = statsEnabled ? raw.prepare(STATEMENTS["stats.upsert"]!) : null;
  function timed<T>(name: StatementName, fn: () => T, rows: (r: T) => number): T {
    if (!statsStmt || name.startsWith("stats.")) return fn();
    const t0 = performance.now(); const out = fn(); const ms = performance.now() - t0;
    statsStmt.run({ name, sql: STATEMENTS[name]!, ms, rows: rows(out), ts: new Date().toISOString() });
    return out;
  }
  const db: NexusDb = {
    raw, statsEnabled,
    run: (n, p = {}) => timed(n, () => { const r = stmt(n).run(p as never); return { changes: Number(r.changes), lastInsertRowid: Number(r.lastInsertRowid) }; }, (r) => r.changes),
    get: <T>(n: StatementName, p: Row = {}) => timed(n, () => stmt(n).get(p as never) as T | undefined, (r) => (r ? 1 : 0)),
    all: <T>(n: StatementName, p: Row = {}) => timed(n, () => stmt(n).all(p as never) as T[], (r) => r.length),
    transaction<T>(fn: () => T): T {
      raw.exec("BEGIN IMMEDIATE");
      try { const out = fn(); raw.exec("COMMIT"); return out; }
      catch (err) { try { raw.exec("ROLLBACK"); } catch { /* already rolled back */ } throw err; }
    },
    close: () => { try { raw.exec("PRAGMA optimize"); } catch { /* best effort */ } raw.close(); },
  };
  return db;
}

function migrate(raw: DatabaseSync): void {
  raw.exec("CREATE TABLE IF NOT EXISTS meta (key TEXT PRIMARY KEY, value TEXT NOT NULL)");
  const cur = Number((raw.prepare("SELECT value FROM meta WHERE key = 'schema_version'").get() as Row | undefined)?.value ?? 0);
  const files = fs.readdirSync(MIGRATIONS_DIR).filter((f) => /^\d{3}\.sql$/.test(f)).sort();
  for (const f of files) {
    const n = Number(f.slice(0, 3)); if (n <= cur) continue;
    raw.exec("BEGIN IMMEDIATE");
    try {
      raw.exec(fs.readFileSync(path.join(MIGRATIONS_DIR, f), "utf8"));
      raw.prepare("INSERT OR REPLACE INTO meta(key,value) VALUES('schema_version', ?)").run(String(n));
      raw.exec("COMMIT");
    } catch (e) { raw.exec("ROLLBACK"); throw e; }
  }
}

import type { NexusDb, Row } from "./open.js";
import { REDUCERS } from "./reducers/index.js";
export type NexusEvent = { kind: string; ts?: string; system_id?: string | null; planet_id?: string | null; moon_id?: string | null;
  voyage_id?: string | null; ship_id?: string | null; provider?: string | null; payload: Record<string, unknown> };
export type EventRow = NexusEvent & { id: number; ts: string };
export type Reducer = (db: NexusDb, ev: EventRow) => void;

export function rowToEvent(r: Row): EventRow {
  return { ...(r as unknown as EventRow), payload: JSON.parse(String(r.payload)) as Record<string, unknown> };
}
export function applyEvent(db: NexusDb, ev: EventRow): void {
  const reducer = REDUCERS[ev.kind];
  if (!reducer) throw new Error(`no reducer for '${ev.kind}'`);
  reducer(db, ev);
}
export function append(db: NexusDb, ev: NexusEvent, precheck?: () => void): EventRow {
  return db.transaction(() => {
    precheck?.();
    const ts = ev.ts ?? new Date().toISOString();
    const { lastInsertRowid } = db.run("events.insert", {
      ts, kind: ev.kind, system_id: ev.system_id ?? null, planet_id: ev.planet_id ?? null, moon_id: ev.moon_id ?? null,
      voyage_id: ev.voyage_id ?? null, ship_id: ev.ship_id ?? null, provider: ev.provider ?? null, payload: JSON.stringify(ev.payload),
    });
    const row = rowToEvent(db.get("events.byId", { id: lastInsertRowid })!);
    applyEvent(db, row);
    return row;
  });
}

// src/db/rebuild.ts
import type { NexusDb } from "./open.js";
import { applyEvent, rowToEvent } from "./events.js";
// delete order respects foreign keys
export const PROJECTION_TABLES = ["verdicts", "decisions", "voyages", "moons", "planets", "ships", "systems"] as const;
export function rebuild(db: NexusDb): { events: number } {
  return db.transaction(() => {
    for (const t of PROJECTION_TABLES) db.raw.exec(`DELETE FROM ${t}`);
    let n = 0;
    for (const r of db.all("events.all")) { applyEvent(db, rowToEvent(r)); n++; }
    return { events: n };
  });
}
export function dumpProjections(db: NexusDb): string {
  const out: Record<string, unknown[]> = {};
  for (const t of [...PROJECTION_TABLES].sort()) out[t] = db.raw.prepare(`SELECT * FROM ${t} ORDER BY rowid`).all();
  return JSON.stringify(out, null, 1);
}

export type Rng = () => number;
export function mulberry32(seed: number): Rng {
  let a = seed >>> 0;
  return () => { a = (a + 0x6d2b79f5) >>> 0; let t = a; t = Math.imul(t ^ (t >>> 15), t | 1); t ^= t + Math.imul(t ^ (t >>> 7), t | 61); return ((t ^ (t >>> 14)) >>> 0) / 4294967296; };
}
export function pick<T>(rng: Rng, items: readonly T[]): T { return items[Math.floor(rng() * items.length)]!; }
export function int(rng: Rng, min: number, max: number): number { return min + Math.floor(rng() * (max - min + 1)); }

export function pickName(rng: Rng, pool: readonly string[], used: Set<string>): string {
  const free = pool.filter((n) => !used.has(n));
  let name = free.length ? pick(rng, free) : pick(rng, pool);
  const ROMAN = ["", "-II", "-III", "-IV", "-V", "-VI", "-VII", "-VIII", "-IX", "-X"];
  for (let i = 1; used.has(name) && i < ROMAN.length; i++) name = `${name.replace(/-[IVX]+$/, "")}${ROMAN[i]}`;
  while (used.has(name)) name = `${name}-${Math.floor(rng() * 1e6)}`;
  used.add(name);
  return name;
}

import { mulberry32, int, type Rng } from "./rng.js";
import { THEMES, pickName } from "./names.js";
export type PlanetKind = "rocky" | "gas_giant" | "ice_giant" | "dwarf";
export type GeneratedMoon = { name: string; orbit_index: number };
export type GeneratedPlanet = { name: string; orbit_index: number; kind: PlanetKind; moons: GeneratedMoon[] };
export type GeneratedSystem = { seed: number; theme: string; planets: GeneratedPlanet[]; belt_after_orbit: 5 };
const OUTER: PlanetKind[] = ["gas_giant", "gas_giant", "ice_giant", "ice_giant"]; // then dwarf forever

export function generateSystem(seed: number, theme = "classic"): GeneratedSystem {
  const rng = mulberry32(seed); const t = THEMES[theme] ?? THEMES["classic"]!;
  const usedP = new Set<string>(), usedM = new Set<string>();
  const planets: GeneratedPlanet[] = [];
  for (let i = 0; i < 6; i++) {
    const moons: GeneratedMoon[] = [];
    const n = int(rng, 1, 4);
    const name = pickName(rng, t.planets, usedP);
    for (let j = 0; j < n; j++) moons.push({ name: pickName(rng, t.moons, usedM), orbit_index: j });
    planets.push({ name, orbit_index: i, kind: "rocky", moons });
  }
  return { seed, theme, planets, belt_after_orbit: 5 };
}
// Discovery is deterministic in (seed, what already exists): derive a sub-seed from the seed and the count.
function subRng(seed: number, salt: number): Rng { return mulberry32((seed ^ (salt * 0x9e3779b9)) >>> 0); }
export function discoverPlanet(seed: number, theme: string, existing: { name: string; orbit_index: number }[]): GeneratedPlanet {
  const t = THEMES[theme] ?? THEMES["classic"]!;
  const orbit = Math.max(-1, ...existing.map((e) => e.orbit_index)) + 1;
  const rng = subRng(seed, 1000 + orbit);
  const used = new Set(existing.map((e) => e.name));
  const outerIndex = orbit - 6;
  return { name: pickName(rng, t.planets, used), orbit_index: orbit, kind: OUTER[outerIndex] ?? "dwarf", moons: [] };
}
export function discoverMoon(seed: number, theme: string, planetOrbit: number, existing: { name: string; orbit_index: number }[], usedNames: Set<string>): GeneratedMoon {
  const t = THEMES[theme] ?? THEMES["classic"]!;
  const orbit = Math.max(-1, ...existing.map((e) => e.orbit_index)) + 1;
  const rng = subRng(seed, 2000 + planetOrbit * 100 + orbit);
  return { name: pickName(rng, t.moons, new Set(usedNames)), orbit_index: orbit };
}

// src/core/git.ts (key parts; port -z parsers from lanes-validate.mjs:460-491 as private functions)
import fs from "node:fs"; import path from "node:path"; import { execFileSync } from "node:child_process";
import { normalizePath } from "../validate/match.js";

export class GitRefusal extends Error { constructor(public readonly args: string[], reason: string) { super(`git refusal: ${reason} (${args.join(" ")})`); } }
export type GitLog = (entry: { args: string[]; cwd: string; ms: number; ok: boolean; stderr?: string }) => void;
const OWNED_BRANCH = /^(nexus|system)\//;

export class Git {
  private readonly wtRoot: string;
  constructor(public readonly repoRoot: string, private readonly opts: { log?: GitLog } = {}) {
    this.wtRoot = this.canon(path.join(repoRoot, ".nexus", "worktrees"));
  }
  canon(p: string): string { const abs = normalizePath(path.resolve(this.repoRoot, p)).replace(/\/+$/, ""); return process.platform === "win32" ? abs.toLowerCase() : abs; }
  private isMainTree(cwd: string): boolean { return this.canon(cwd) === this.canon(this.repoRoot); }
  private underWorktrees(p: string): boolean { return this.canon(p).startsWith(this.wtRoot + "/"); }

  private refuse(args: string[], cwd: string): void {
    const [cmd, ...rest] = args;
    if (cmd === "push") throw new GitRefusal(args, "nothing is ever pushed");
    if (["checkout", "switch", "reset", "stash", "rebase", "commit", "merge", "clean"].includes(cmd!) && this.isMainTree(cwd)) throw new GitRefusal(args, "the human's working tree is never written to");
    if (cmd === "branch" && rest.some((a) => a === "-D" || a === "-d" || a === "--delete")) {
      const name = rest.find((a) => !a.startsWith("-")); if (!name || !OWNED_BRANCH.test(name)) throw new GitRefusal(args, "only nexus/* and system/* branches may be deleted");
    }
    if (cmd === "worktree" && rest[0] === "remove") { const dir = rest.find((a) => !a.startsWith("-") && a !== "remove"); if (!dir || !this.underWorktrees(path.resolve(cwd, dir))) throw new GitRefusal(args, "only worktrees under .nexus/worktrees may be removed"); }
    if (cmd === "worktree" && rest[0] === "add") { const dir = rest.find((a) => !a.startsWith("-") && a !== "add"); if (!dir || !this.underWorktrees(path.resolve(cwd, dir))) throw new GitRefusal(args, "worktrees are created only under .nexus/worktrees"); }
  }
  runRaw(args: string[], o: { cwd?: string } = {}): string {
    const cwd = o.cwd ?? this.repoRoot; this.refuse(args, cwd); const t0 = performance.now();
    try { const out = execFileSync("git", ["-c", "core.quotepath=false", "-C", cwd, ...args], { encoding: "utf8", stdio: ["ignore", "pipe", "pipe"] }); this.opts.log?.({ args, cwd, ms: performance.now() - t0, ok: true }); return out; }
    catch (err) { const e = err as { stderr?: string; message: string }; this.opts.log?.({ args, cwd, ms: performance.now() - t0, ok: false, stderr: e.stderr }); throw new Error(`git ${args.join(" ")} failed: ${(e.stderr || e.message).trim()}`); }
  }
  run(args: string[], o: { cwd?: string } = {}): string { return this.runRaw(args, o).trimEnd(); }
  revParse(ref: string, cwd?: string): string { return this.run(["rev-parse", "--verify", `${ref}^{commit}`], { cwd }); }
  headSha(cwd?: string): string { return this.revParse("HEAD", cwd); }
  branchExists(name: string): boolean { return this.run(["branch", "--list", name]) !== ""; }
  createBranch(name: string, fromSha: string): void { this.run(["branch", name, fromSha]); }
  deleteBranch(name: string, o: { force?: boolean } = {}): boolean {
    if (!OWNED_BRANCH.test(name)) throw new GitRefusal(["branch", "-D", name], "only nexus/* and system/* branches may be deleted");
    try { this.run(["branch", o.force ? "-D" : "-d", name]); return true; } catch { return false; }
  }

  worktreeAdd(dir: string, branch: string, fromSha: string): void {
    if (!this.underWorktrees(dir)) throw new GitRefusal(["worktree", "add", dir], "worktrees are created only under .nexus/worktrees");
    this.clearEmptyShell(dir);
    if (this.worktreeList().includes(this.canon(dir))) return;            // check-before-act: already there
    if (fs.existsSync(dir)) throw new Error(`worktree path exists but is not registered: ${dir}`);
    this.ensureExcluded(); fs.mkdirSync(path.dirname(dir), { recursive: true });
    if (this.branchExists(branch)) this.run(["worktree", "add", dir, branch]); else this.run(["worktree", "add", dir, "-b", branch, fromSha]);
  }
  worktreeRemove(dir: string, o: { force?: boolean } = {}): void {
    if (!this.underWorktrees(dir)) throw new GitRefusal(["worktree", "remove", dir], "only worktrees under .nexus/worktrees may be removed");
    const registered = this.worktreeList().includes(this.canon(dir));
    if (registered && fs.existsSync(dir)) this.run(["worktree", "remove", ...(o.force ? ["--force"] : []), dir]);
    else if (registered) this.run(["worktree", "prune"]);
    if (fs.existsSync(dir)) fs.rmSync(dir, { recursive: true, force: true });   // Windows leaves the folder
  }
  statusPaths(cwd: string): string[] { return statusPathsZ(this.runRaw(["status", "--porcelain", "-z", "--untracked-files=all"], { cwd })); }
  diffPaths(cwd: string, range: string | null, o: { cached?: boolean } = {}): string[] { return diffPathsZ(this.runRaw(["diff", "--name-status", "-z", ...(o.cached ? ["--cached"] : []), ...(range ? [range] : [])], { cwd })); }
  untrackedPaths(cwd: string): string[] { return this.runRaw(["ls-files", "--others", "--exclude-standard", "-z"], { cwd }).split("\0").filter(Boolean).map(normalizePath); }
  commitAll(cwd: string, message: string, author: { name: string; email: string }): string | null {
    this.run(["add", "-A"], { cwd });
    if (this.run(["status", "--porcelain"], { cwd }) === "") return null;
    this.run(["-c", `user.name=${author.name}`, "-c", `user.email=${author.email}`, "commit", "-q", "-m", message], { cwd });
    return this.headSha(cwd);
  }
  mergeNoFF(cwd: string, branch: string, message: string): { ok: true; sha: string } | { ok: false; conflict: true; files: string[] } {
    try { this.run(["merge", "--no-ff", "-m", message, branch], { cwd }); return { ok: true, sha: this.headSha(cwd) }; }
    catch {
      const files = this.run(["diff", "--name-only", "--diff-filter=U"], { cwd }).split(/\r?\n/).filter(Boolean).map(normalizePath);
      this.run(["merge", "--abort"], { cwd });
      return { ok: false, conflict: true, files };
    }
  }
}
```
`refuse()` runs before every command, including the ones the class itself issues — the class cannot bypass its own list. import { matchAny, normalizePath } from "./match.js";
export function attentionMatches(touch: string[], attention: Record<string, string[]>): Record<string, string[]> {
  const out: Record<string, string[]> = {};
  for (const [category, patterns] of Object.entries(attention)) {

// src/providers/fake/index.ts
import fs from "node:fs"; import path from "node:path"; import { setTimeout as sleep } from "node:timers/promises";
import type { ProviderAdapter, Job, DispatchCtx, AgentEvent, ErrorClass } from "../adapter.js";
export function createFakeAdapter(scriptsDir: string, opts: { pick?: (job: Job) => string } = {}): ProviderAdapter {
  const pick = opts.pick ?? ((job: Job) => job.prompt.match(/^FAKE-SCRIPT:\s*(\S+)/m)?.[1] ?? (job.role === "review" ? "review-approve" : "happy"));
  const now = () => new Date().toISOString();
  return {
    id: "fake", roles: ["implement", "review"],
    async *dispatch(job: Job, ctx: DispatchCtx): AsyncIterable<AgentEvent> {
      const script = JSON.parse(fs.readFileSync(path.join(scriptsDir, `${pick(job)}.json`), "utf8")) as FakeScript;
      for (const step of script.steps) {
        if (ctx.signal.aborted) return;
        if (step.delay_ms) await sleep(step.delay_ms);
        if ("text" in step) yield { kind: "text", ts: now(), data: { text: step.text } };
        else if ("tool" in step) yield { kind: "tool_use", ts: now(), data: { name: step.tool, input: step.input } };
        else if ("write" in step) { const p = path.join(ctx.cwd, step.write.path); fs.mkdirSync(path.dirname(p), { recursive: true }); fs.writeFileSync(p, step.write.content); yield { kind: "file_changed", ts: now(), data: { path: step.write.path } }; }
        else if ("usage" in step) yield { kind: "usage", ts: now(), data: step.usage };
        else if ("error" in step) { yield { kind: "error", ts: now(), data: { classification: step.error.classification, message: step.error.message } }; return; }
        else if ("crash" in step) throw new Error(step.crash);
        else if ("done" in step) {
          const d = step.done;
          const report = job.role === "review"
            ? { verdict: d.verdict ?? "APPROVE", reasoning: d.reasoning ?? "", delta_spec: d.delta_spec, raw: `VERDICT: ${d.verdict ?? "APPROVE"}\n${d.reasoning ?? ""}` }
            : { status: d.status ?? "IMPLEMENTED", raw: `STATUS: ${d.status ?? "IMPLEMENTED"}` };
          yield { kind: "done", ts: now(), data: { report, session_id: `fake-${job.voyageId}` } }; return;
        }
      }
    },
    classify(): ErrorClass { return "unknown"; },
    async fuel() { return { source: "unknown" as const }; },
  };
}
